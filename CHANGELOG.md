# Изменения

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Добавлено
- `bin/zapret-manager doctor` — диагностический отчёт: модули ядра, счётчики
  nfqueue, давность списков, проверка файлов, на которые ссылается стратегия.
- Снимки состояния перед перезапуском службы
  (`~/.local/state/zapret-discord-youtube/incidents/`).
- Плановый перезапуск службы как обходная мера: `zapret-manager autorestart on 12`.
  Только systemd, по умолчанию выключен.
- `zapret.lock` с пинами версий и контрольными суммами; `tools/update-lock.sh`
  для их пересчёта. Без заполненных сумм — предупреждение,
  с `--strict` — отказ.
- Тесты (`tests/run.sh`) и линтер переносимости (`tools/lint-portability.sh`).
- CI: shellcheck, переносимость, синтаксис конфигов, тесты на GNU и на busybox,
  `nix flake check`.

### Изменено
- Загрузчик стратегий вместо 21 самостоятельного конфига: общий `config`
  собирает `NFQWS_OPT` из фрагмента `strategies/<имя>` и включённых
  `fixes/<имя>`. Было ~3500 строк с дублированием, стало ~230. Основа взята
  из экспериментальной ветки strategy-loader.
- Каталог `configs/` заменён на `strategies/`; добавлен `fixes/`.
- Выбор стратегии — запись имени в `/opt/zapret/zapret.strategy`, а не
  подмена файла конфигурации.
- `config` обновляется только если пользователь его не правил; иначе рядом
  появляется `config.new`.
- NixOS: `configName` → `strategyName`, `extraConfigs` → `extraStrategies`,
  `derivedConfigs` → `derivedStrategies`; добавлены `extraFixes` и
  `enabledFixes`. Старые имена опций переименованы через
  `mkRenamedOptionModule`. `nfqwsAppend` теперь создаёт обычный фикс, из-за
  чего удалён awk-скрипт, вживлявший правила в середину `NFQWS_OPT`.
- Скрипты переписаны и разложены: `bin/` для команд, `lib/` для общих модулей.
  `setup.sh` остался точкой входа для `curl | bash`, но стал тонким бутстрапом.
- Файлы проекта переехали из `~/zapret-configs` в каталоги XDG. Перенос
  выполняется автоматически при первом запуске `zapret-setup`.
- Вместо алиасов в конфиге оболочки — команды в `~/.local/bin`.
- Конфиги переименованы к единому виду: `general-alt` вместо `general(ALT)`,
  `general-simple-fake` вместо `general (SIMPLE FAKE)` и так далее.
  Старые имена принимаются с предупреждением.
- `/opt/zapret` остаётся под root. Запись в hostlists идёт с повышением
  привилегий по факту недоступности пути, а не по предположению о владельце.
- Блок в `/etc/hosts` ограничен маркерами: обновляется целиком и удаляется,
  а не накапливается.

### Исправлено
- `exit` внутри подстановки команд не прерывал скрипт: при отсутствии sudo
  `setup.sh` продолжал работу с текстом ошибки в переменной, а `install.sh` —
  с пустой, выполняя команды без повышения прав.
- `update-rd.d` вместо `update-rc.d` — автозапуск на AntiX не настраивался.
- `modrope` вместо `modprobe` — модуль `nfnetlink_queue` не подгружался
  на Secureblue.
- `ps -p 1 -o comm=` не работает с busybox ps: на Alpine система инициализации
  не определялась. Теперь читается `/proc/1/comm`.
- Пустой каталог конфигов давал меню с несуществующим пунктом (нет `nullglob`).
- `rm -rf "$HOME/tmp"/*` удалял пользовательские файлы; используется `mktemp`.
- Коммит проекта всегда сохранялся как `main`: имя каталога в архиве ветки
  не содержит хеша. Теперь берётся из GitHub API.
- Временные каталоги обновления не удалялись из-за `exec` в обход EXIT-trap.
- SELinux-модуль собирался прямо в каталоге репозитория, оставляя `.mod`/`.pp`.

### Удалено
- `configs/old configs/` — стратегии больше не работают.

### Устарело
- `setup.sh` как установщик (стал бутстрапом), `install.sh` и
  `utils-zapret.sh` — оставлены шимами. **Будут удалены через два релиза.**
- Старые имена конфигураций. Таблица синонимов —
  `configs/legacy-names.map` и `legacyConfigNames` в `nixos/package.nix`.
  **Будет удалена через два релиза.**

### Добавлено (продолжение)
- Схема стратегий из экспериментальной ветки: общий загрузчик `config`,
  фрагменты `strategies/`, компонуемые `fixes/`, состояния
  `zapret.strategy` и `zapret.fixes`.
- `zapret-setup --uninstall` и `--purge` — полное удаление с показом плана.
- `zapret-manager report` — отчёт для issue одним файлом (права 600).
- Переопределение внешних адресов через переменные окружения
  (`ZDY_REPO_SLUG`, `ZDY_BRANCH`, `ZDY_FLOWSEAL_SLUG` и другие) для проверки
  на форке.
- Контрольные суммы для файлов службы dinit (`dinit_sha256` в `zapret.lock`).

### Исправлено (продолжение)
- `shopt -p nullglob` возвращает 1, когда опция выключена: под
  `set -euo pipefail` это молча роняло `zapret-config --list`.
- Каталог состояния и снимки инцидентов создавались с правами 755, хотя
  содержат записи conntrack. Теперь 700, отчёт — 600.
- `package.nix` патчил `WS_USER` в несуществующем каталоге `configs`, и патч
  всё равно затирался последующим копированием `config`.
- Проверка ссылок на файлы стратегии была продублирована в трёх местах.
