# Что подлежит удалению

Список существует по одной причине: совместимость, которую никто не удаляет,
живёт вечно. Каждая запись здесь — код, который написан ради людей,
установивших проект до перехода на новую схему, и который должен исчезнуть.

Проверяется тестом в `tests/run.sh`: если запись есть здесь, соответствующий
код должен существовать, и наоборот. Разъехаться незаметно они не смогут.

## Порядок удаления

Отсчёт идёт от **первого релиза с новой схемой** — того, в котором появились
`bin/`, `lib/` и загрузчик стратегий. Пока он не вышел, удалять нельзя:
именно эти файлы позволяют уже установленным пользователям получить
обновление вообще.

| Что | Файлы | Удалить после |
|---|---|---|
| Шимы старых точек входа | `install.sh`, `utils-zapret.sh` | 2 релизов |
| Заглушка каталога конфигураций | `configs/README.md` | 2 релизов |
| Таблица старых имён стратегий | `strategies/legacy-names.map`, `legacyStrategyNames` в `nixos/package.nix`, `strategy_resolve_name` в `lib/strategy.sh` | 2 релизов |
| Перенос со старой раскладки | `migrate_legacy_layout`, `remove_legacy_aliases` в `bin/zapret-setup`, режим `legacy` в `lib/paths.sh` | 3 релизов |
| Синоним `zapret-utils` | симлинк в `install_commands` (`bin/zapret-setup`) | 2 релизов |
| Возврат владельца `/opt/zapret` | `fix_legacy_ownership` в `bin/zapret-setup` | 3 релизов |

## Почему нельзя удалить прямо сейчас

**Шимы.** Апдейтер прежних версий отказывается ставить обновление, если не
находит в архиве `setup.sh`, `install.sh` и `utils-zapret.sh`. Убрать их до
первого релиза — значит навсегда лишить обновлений всех, кто ещё не перешёл:
починить это удалённо будет уже нечем, останется только переустановка руками.

**Таблица имён.** У пользователей NixOS в конфигурации написано
`configName = "general(ALT)"`. Без таблицы их сборка упадёт при первом же
`nixos-rebuild` после обновления flake.

**Перенос раскладки.** Проект переехал из `~/zapret-configs` в каталоги XDG.
Пока есть машины со старым расположением, перенос нужен. Срок больше, чем
у остального: человек может не обновляться полгода.

**Возврат владельца.** На машинах, где старый `setup.sh` сделал
`chown` `/opt/zapret` на пользователя, каталог остаётся писабельным для
непривилегированного процесса. С загрузчиком стратегий это означает
выполнение произвольного кода от root при каждом старте службы, поэтому
проверка и предложение вернуть `root` должны пережить миграцию с запасом.

## Что должно быть сделано до удаления

- [ ] Первый релиз с новой схемой вышел в `main`
- [ ] В `CHANGELOG.md` названы конкретные версии, в которых удаляется каждый пункт
- [ ] Шимы хотя бы один релиз печатают предупреждение (сейчас печатают)
- [ ] В README указано, что старые имена стратегий устарели (указано)

## Отдельно: обходные меры

Не совместимость, но тоже код с ограниченным сроком жизни.

**`lib/autorestart.sh`** — плановый перезапуск службы. Существует, пока не
найдена причина того, что через несколько часов часть трафика перестаёт
обходиться. Когда причина найдётся и будет устранена, модуль удаляется
целиком, вместе с пунктом меню, слепками таймера и разделом в документации.
Оставлять «на всякий случай» нельзя: он маскирует симптом и мешает заметить
повторение проблемы.
