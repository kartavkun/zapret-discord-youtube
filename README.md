# Zapret для OpenWrt

Ветка `openwrt` адаптирует стратегии этого репозитория для роутера:
BusyBox `/bin/sh`, запуск от root и штатная служба `/etc/init.d/zapret`
(procd). Bash, sudo, systemd и git на роутере не нужны.
Это конфигурации для **bol-van/zapret (nfqws)**, не zapret2.

## Установка

Скопируйте содержимое этой ветки на роутер, например в
`/root/zapret-configs`. Ветка пока существует локально: перед скачиванием
с GitHub её нужно опубликовать. Запускайте файлы из каталога проекта,
а не через `curl | sh`.

```sh
cd /root/zapret-configs
sh setup.sh
```

Для HTTPS-загрузок нужны `wget` (или `curl`) и `ca-bundle`.
При необходимости установите их через пакетный менеджер прошивки:

```sh
# OpenWrt с opkg
opkg update
opkg install wget ca-bundle
# Либо OpenWrt с apk
apk update
apk add wget ca-bundle
```

`setup.sh` скачает релиз официального zapret во временный каталог `/tmp`
и запустит его интерактивный `install_easy.sh`. Он выберет бинарники под
архитектуру, установит зависимости и настроит интеграцию с firewall.
Выберите nfqws и подходящий firewall (nftables для firewall4).
После завершения будет применена стратегия `general` и включён автозапуск.
При уже установленном zapret скачивание и переустановка пропускаются.
Существующий `/opt/zapret` скрипт не удаляет.

Если в RAM недостаточно места для архива релиза, заранее распакуйте
официальный релиз на USB-накопитель и передайте каталог:

```sh
sh setup.sh /mnt/usb/zapret-ВАША_ВЕРСИЯ
```

Этот аргумент предназначен для первой установки. При существующей установке
аргумент `setup.sh` — имя стратегии; для переключения удобнее `install.sh`.
Официальный установщик размещает минимальную установку в `/opt/zapret`.
Свободное место под неё, списки и необходимые пакеты должно быть на overlay
или внешнем накопителе. Архив полного релиза требует существенно больше места.

## Стратегии и управление

```sh
sh install.sh --list
sh install.sh 'general (SIMPLE FAKE)'
sh utils-zapret.sh status
sh utils-zapret.sh restart
sh utils-zapret.sh game udp
sh utils-zapret.sh game off
sh utils-zapret.sh log
sh utils-zapret.sh restore
```

Доступны актуальные файлы из `configs/`; архивные полные Linux-конфиги из
`configs/old configs` не применяются. Стратегии зависят от провайдера.
Файлы fake, требуемые выбранной стратегией, скачиваются из Flowseal,
если их ещё нет в установленном zapret. При отсутствии файла или неподдерживаемых
опциях применение завершится ошибкой.

Перед заменой `/opt/zapret/config` выполняется `nfqws --dry-run`.
Предыдущий config сохраняется в `/opt/zapret/config.backup`.
При ошибке команды restart он восстанавливается. Это не проверка доступности
YouTube/Discord: её нужно провести с устройства в LAN после применения.
Списки и скачанные fake-файлы не откатываются вместе с config.
Пользовательские `*-user.txt` и состояние игрового фильтра сохраняются.
Остальные списки обновляются из локальной копии проекта при применении.

Службой также можно управлять напрямую:
`/etc/init.d/zapret start|stop|restart|enable|disable|status`.
Автоматическое обновление с ветки `main` убрано: обновляйте локальную копию
именно из `openwrt`, затем повторно применяйте стратегию.

## Сеть роутера

В общей конфигурации firewall определяется средствами zapret, IPv6 разрешён,
лимиты ipset и число потоков DNS уменьшены. `FLOWOFFLOAD=none` отключает
flow offloading при настройке firewall средствами zapret: иначе часть
трафика может обходить NFQUEUE. Это может снизить скорость маршрутизации.
Игровой фильтр по умолчанию выключен; `all` отправляет в обработку много портов
и увеличивает нагрузку.

Для своих сетей создайте `/opt/zapret/config.router`, например:

```sh
OPENWRT_LAN="lan guest"
# При необходимости явно укажите логические интерфейсы OpenWrt:
# OPENWRT_WAN4="wan"
# OPENWRT_WAN6="wan6"
# DISABLE_IPV6=1
# FLOWOFFLOAD=software
```

Затем повторите `sh install.sh 'ИМЯ СТРАТЕГИИ'`. Файл `config.router`
вставляется после общей части и сохраняется при переключении стратегии.
Без него общая часть заменит прежние индивидуальные параметры config;
перенесите нужные параметры перед первым применением.

Реализация опирается на [официальную документацию zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md)
и [официальный установщик](https://github.com/bol-van/zapret/blob/master/install_easy.sh).
На реальном роутере эта ветка пока не проверена.
