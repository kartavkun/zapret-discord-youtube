# Каталог оставлен для совместимости

Конфигурации переехали в [`../strategies/`](../strategies/) и стали
фрагментами: общий загрузчик — `../config`, стратегия — десяток строк
с `NFQWS_STRATEGY_OPT`.

Сам каталог удалить пока нельзя. Апдейтер прежних версий проверяет архив
обновления на наличие `setup.sh`, `install.sh`, `utils-zapret.sh`, `configs`,
`hostlists` и `utils`, и без каталога `configs` отказывается ставить
обновление со словами «в архиве нет configs». То есть все, кто ещё не
перешёл на новую версию, потеряли бы возможность обновиться из меню —
навсегда, потому что чинить это было бы уже нечем.

Удаляется вместе с шимами `install.sh` и `utils-zapret.sh` — через два
релиза после выхода версии с каталогом `bin/`.
